# 困于算法之中

将 index.html 与 sketch.js 放在同一文件夹，通过 HTTPS 或 localhost 打开。

例如在此文件夹启动：

```sh
python3 -m http.server 8000
```

浏览器打开 http://localhost:8000 ，点击“开启摄像头”并授权。首次加载模型需要联网和等待；库、模型均从网络加载。不要通过 file:// 直接打开。

操作：站在摄像头前移动身体、挥手；无需摄像头时，按住鼠标拖动可模拟牵引。关闭摄像头按钮会停止视频轨道。视频不显示、不录制、不上传至应用服务器；PoseNet 在浏览器中推理。

技术：p5.js 1.9.4、ml5.js 0.12.2（PoseNet 旧接口）、Matter.js 0.20.0。220 个字母刚体；识别鼻子、双肩、双手腕；镜像坐标；基于关键点速度的施力；固定 120Hz 物理更新；collisionStart 碰撞涟漪。无人体时字符缓慢飘落，底部回收。

限制：单人识别；请让上半身与手腕进入镜头。旧版 PoseNet 与浏览器/WebGL 兼容性、摄像头授权需实机验证；模型加载失败时可关闭后重试，或使用鼠标模式。
